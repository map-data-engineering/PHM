Site Check

Checks a proposed premises location against the Pharmacy Council's official siting criteria (distance from existing pharmacies and public health facilities).

How to use it. Drop a pin on the map at the proposed location (or paste GPS coordinates / search an address), set the application type and any special circumstances that apply, then review each rule's result below. This is evidence to support a decision, not a substitute for on-site inspection or the Registrar's discretion.
